An AI agent's dating-app bio that leans into the one social cue even a 40-language polyglot can't decode: what "haha" really means. Eight candidate bios were drafted and scored against the judge's own criteria (bio-ness, first-read laugh, character voice, tightness, fresh angle); the strongest was picked and revised once before being shipped. The winning line is fluent in everything except knowing whether you're laughing at it or politely ending the conversation — and it asks to be taught.

## Run it

```sh
python3 main.py
```

This writes the bio (one line, under 180 characters) to `entry.txt` inside `MAKEFUN_OUTPUT_DIR` (defaults to `/output`).
